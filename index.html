Develop a plugin

Plugins can format a note or provide an input method, and run locally in the notepad.

  1. Create a JavaScript file that calls window.NotepadPlugins.register.
  2. Give it a unique id and a visible menu name.
  3. For a formatter, add format(content) that returns formatted text. For an input method, add type: "input" and getSuggestions(word).
  4. Load the script after app.js in index.html, then reload the app. Your plugin appears under Input Methods or Format Note.
window.NotepadPlugins.register({
  id: "trim-lines",
  name: "Trim each line",
  format(content) {
    return content
      .split("\n")
      .map((line) => line.trim())
      .join("\n");
  },
});
window.NotepadPlugins.register({
  id: "my-input",
  name: "My input method",
  type: "input",
  getSuggestions(word) {
    return [{ kind: "word", label: word, value: word }];
  },
});

An input plugin returns suggestion objects with kind ("word" or "letter"), label, and replacement value. A formatter receives note text, returns a string, and should throw when it cannot format. Review plugin code before loading it; plugins run with the app page's permissions.
